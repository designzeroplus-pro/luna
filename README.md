# LUNA

LUNA는 로고를 만들고, 템플릿으로 명함을 디자인해 인쇄용 PDF / JPG로 내려받는 웹 서비스입니다.
빌드 과정이 없는 정적 웹앱이라 서버가 필요 없습니다(모든 처리가 브라우저에서 이루어집니다).

## 실행

```bash
python3 -m http.server 5391
```

브라우저에서 http://localhost:5391 을 엽니다.

## 기능

- **메인 템플릿 갤러리**: 첫 화면에서 모든 템플릿의 앞·뒷면을 보고, 미니멀·클래식·볼드로 걸러볼 수 있습니다. 이름과 회사명을 입력하면 갤러리 전체가 내 정보로 바뀌고, 템플릿을 누르면 편집기(`#edit`)로 이동합니다.
- **로고 만들기**: 심볼(이니셜·산·파도·잎·별·번개·궤도) × 모양 × 채움/외곽선, 가로·세로 배치, 글꼴과 색상을 고를 수 있고 PNG(투명 배경, 흰색 버전 포함)로 받을 수 있습니다. 갖고 있는 로고 이미지를 업로드해도 됩니다.
- **명함 템플릿 12종**: 에어, 세리프 스튜디오, 시그널, 모노그램, 폴리오, 그로브, 오프셋, 타입 포스터, 인덱스, 버소, 버티컬, 시그니처. 여백과 타이포그래피 중심으로 전면 재설계했고, 앞면은 브랜드, 뒷면은 연락처로 구성합니다. 선택 목록에서 양면을 함께 비교할 수 있습니다.
- **템플릿 추천 스타일**: 각 디자인의 추천 색상과 DM Sans / Bodoni Moda 서체 조합을 기본 적용합니다. 한글은 본고딕 / 본명조를 사용합니다. 직접 색상과 글꼴을 변경할 수 있습니다.
- **브랜드 표현**: 회사명, 브랜드 소개 / 슬로건, 이니셜을 활용합니다. 로고 탭에서 '명함에 로고 적용'을 켜면 만든 로고나 업로드한 로고로 교체합니다. 이니셜은 로고 탭에서 편집합니다.
- **다운로드**
  - JPG: 300/600dpi, 도련 1mm 포함(92×52mm)을 선택할 수 있고 파일에 DPI 정보가 기록됩니다.
  - 인쇄소용 PDF: 앞·뒷면 2페이지에 도련과 재단선이 들어갑니다.
  - A4 10장 배치 PDF: 사무실 프린터로 출력하는 용도입니다.
- 입력한 내용은 브라우저(localStorage)에 자동 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 스타일 |
| `logo.js` | 로고 생성기 (Canvas) |
| `templates.js` | 명함 템플릿. mm 단위 좌표로 그려서 어떤 해상도로도 렌더링할 수 있습니다 |
| `app.js` | 상태 관리, UI, 내보내기 (jsPDF) |

## 템플릿 추가하기

`templates.js`의 `TEMPLATES` 배열에 `{ id, name, description, palette: [ink, paper], display, front(ctx, d), back(ctx, d) }`를 추가하면 됩니다. 템플릿 수와 선택 목록은 자동으로 갱신됩니다.
좌표는 재단선 기준 90×50mm이고, 배경은 `fillAll()`로 도련 영역까지 채웁니다.

`text()`는 긴 글자의 서체 크기를 비례 조절하고, `block()`은 이메일·주소·한글을 지정 영역 안에 줄바꿈합니다. `wordmark()`는 회사명 또는 선택한 로고를 그립니다. 빈 정보는 표시하지 않습니다.

기존 저장 데이터는 첫 실행 시 새 컬렉션의 기본 스타일로 전환하며 입력 정보·로고 설정·업로드 파일은 유지합니다. 종이 질감과 실제 인쇄 후가공은 파일에 합성하지 않습니다.
